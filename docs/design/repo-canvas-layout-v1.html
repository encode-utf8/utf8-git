① 拥挤的根因：徽标吃光了泳道间隙

对照模式里徽标浮在卡片上方 8px、高 18px，而泳道净间隙只有 16px——相邻两条泳道的徽标互相侵入。

卡片 48 + 徽标侵入 8 + 8 = 64 = 泳道距（已被吃满）

L2 / L3 把徽标收进卡片内部，间隙全部还给曲线与呼吸空间。

② L2 单行标签卡（推荐）

  • 一行：标题（截断）+ 徽标数字 chip，卡高 28px
  • 作者 / SHA / 时间移到悬停浮层，点击仍是右下角详情面板
  • 泳道距 64 → 52、画布更矮；卡片加宽到 176px，标题少截断
  • 代价：每行可见卡片略少（约 6 张 vs 8 张），换来的是行内不挤
卡片 28 + 间隙 24 = 52

③ L3 双行入卡（信息全可见）

  • 第一行标题 + 完整徽标；第二行作者·SHA·时间
  • 卡高 50px、泳道距 72，画布约 300px 高
  • 适合「不想悬停就要看全」的偏好
卡片 50 + 间隙 22 = 72
