五处取舍与结论

  1. 节点形态 → 点 + 标签（已定；卡片形态未采用，仅在上方开关里保留对照）。
  2. 密度 → 36 / 52 两档都做，作为用户可切换的界面选项并记住选择（已定，默认 36）。
  3. 删除区 → 平时隐藏，拖动分支芯片时才浮出（已定）。
  4. 详情卡 → 固定贴画布右下角，用边框 + 阴影 + 浅色标题栏强化存在感（已定）。
  5. 时间刷子 → 不进 P0，P1 再做（牵扯现有 range 过滤与「选中提交重新锚定」逻辑）。

P0 落地范围：画布容器 + 分支芯片条 + 拖拽建分支（落点命名）+ 拖拽删除（仍走确认面板）+ 右下角详情卡 + 密度选项；旧按钮工具栏保留为键盘与无障碍路径。缩放、时间刷子、径向菜单进 P1。
