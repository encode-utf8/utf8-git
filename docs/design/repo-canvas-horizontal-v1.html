曲线 = 分叉 / 合并（父子关系）

① 轴向怎么定

横轴 = 时间，纵轴 = 泳道（原泳道图旋转 90°）。跨泳道的曲线是父子关系（分叉 / 合并），同泳道由泳道轨表示。左旧右新是默认，切「左新右旧」后最新提交贴在左端。

② 间距两种口径

  • 等距：每条提交固定宽度，密、好扫读，但时间不成比例。
  • 时间比例：x 与真实时间成正比，会出现空档（仓库沉寂期），但时间刷子能和画布对齐。

③ 分支方块的位置

当前是固定顶栏（永远可见、拖拽目标稳定）。另一种是「跟随 tip 提交」贴在对应泳道上方，随横向滚动移动，视觉上更能说明分支属于哪条线，但分支多时会重叠。

④ 保留与变化

保留：拖提交建分支、拖方块开 PR、拖到竖轨删除、点节点看详情、时间刷子、筛选与分享链接。
变化：虚拟窗口从「按 scrollTop 切片」改为「按 scrollLeft 切片」；行高语义改为泳道高度。

⑤ 落地代价

  • 虚拟窗口从 scrollTop 改 scrollLeft：列宽固定，算法同构，改动集中在切片与行渲染。
  • 行高语义变成泳道高度；密度 36/52 改为泳道间距 48/64。
  • 等距模式下时间刷子与画布不同构（刷子按时间比例），需二选一或让刷子也按序号。
  • 横向滚动手势与拖拽在触摸端冲突更明显，需长按阈值。
